# DailyTodo Backup

This private repository stores a backup of the DailyTodo project.

The release `cleanup-backup-20260717-014140` contains:

- `DailyTodo-master-a9cd1e1.zip`: source snapshot of master commit `a9cd1e1`.
- `DailyTodo-worktree-cleanup-backup-20260717-014140.zip`: Git bundle and recovery material saved before worktree cleanup.
- `BACKUP-MANIFEST.txt`: SHA-256 checksums and restore notes.

The local project remote is configured to this repository. Git push will resume normally when the local Git HTTPS connection is available.
