# DailyTodo 多对话快速上手

> 适合每天直接照着做，不想每次都重新想流程时使用。

---

## 1. 先记住一句话

```text
永远先找「项目总控」定方向，
再让其他部门分析或执行，
最后把结果回传给「项目总控」。
```

---

## 2. 第一次开始时怎么做

先打开：

- `DailyTodo｜项目总控`

发送：

```text
请开始 DailyTodo 规范化第 1 阶段：整体项目理解和总规划。

要求：
1. 先只理解项目，不改代码
2. 扫描项目结构、README、SPEC、package.json、src、electron、scripts、docs
3. 梳理产品定位、功能地图、技术栈、目录结构、主进程/渲染进程/数据层关系
4. 梳理任务系统、Obsidian 集成、AI Review、设置系统、验证体系
5. 输出项目理解报告
6. 输出后续各部门对话应该分别做什么
7. 最后给我一个可以同步给其他对话的项目总控摘要
```

目标是拿到两样东西：

1. 项目理解报告
2. 项目总控摘要

---

## 3. 第二步做什么

把“项目总控摘要”复制给这三个部门先做分析：

- `DailyTodo｜产品PMO`
- `DailyTodo｜工程效能部`
- `DailyTodo｜验证部`

统一发这种模板：

```text
这是项目总控给你的背景摘要：

【粘贴项目总控摘要】

请你只做分析，不改代码。

目标：
1. 分析你负责的范围
2. 说明当前问题
3. 给出规范化建议
4. 标出风险点
5. 最后输出「同步给项目总控的摘要」
```

---

## 4. 第三步做什么

把这三个部门的摘要再贴回：

- `DailyTodo｜项目总控`

发送：

```text
这是几个部门的阶段摘要：

【粘贴产品PMO摘要】
【粘贴工程效能部摘要】
【粘贴验证部摘要】

请你：
1. 合并到总规划
2. 判断规范化优先级
3. 决定下一步应该先派给哪个专业部门
4. 给我下一步可直接复制的提示词
```

---

## 5. 什么时候找专业部门

当项目总控明确分配任务后，再去找这些部门：

- `DailyTodo｜前端部`
- `DailyTodo｜桌面主进程部`
- `DailyTodo｜数据业务部`
- `DailyTodo｜设置系统部`
- `DailyTodo｜Obsidian集成部`
- `DailyTodo｜AI Review部`
- `DailyTodo｜视觉设计部`
- `DailyTodo｜文档部`
- `DailyTodo｜发布部`

原则：

```text
先分析，再小步执行。
一次只做一个范围。
一次最好只让一个部门真正改代码。
```

---

## 6. 改代码前怎么发

给执行部门发：

```text
这是项目总控分派给你的任务：

【粘贴任务描述】

要求：
1. 先说明修改计划
2. 只修改本次指定范围
3. 不碰未授权模块
4. 小步修改
5. 改完运行相关验证
6. 最后输出「同步给项目总控的摘要」
```

---

## 7. 改代码前一定要先问验证部

在真正执行前，建议先找：

- `DailyTodo｜验证部`

发送：

```text
项目总控准备让【某部门】修改【某模块】。

请你给出：
1. 修改前应该运行哪些检查
2. 修改后应该运行哪些验证
3. 需要手动测试哪些场景
4. 如果失败应该如何定位
```

---

## 8. 每次做完都要回项目总控

把部门输出的摘要贴回：

- `DailyTodo｜项目总控`

发送：

```text
这是【某部门】的阶段摘要：

【粘贴摘要】

请你：
1. 合并到总规划
2. 判断是否影响当前路线
3. 决定下一步派给谁
4. 给我下一步可复制提示词
```

---

## 9. 最常见的错误用法

不要这样：

```text
前端部在改 App.tsx
设置系统部同时改 SettingsPanel.tsx
视觉设计部同时改 globals.css
AI Review部同时改报告页面
```

也不要这样：

```text
帮我一次性把整个项目全部规范化并重构
```

正确方式：

```text
总控先规划
部门先分析
验证先介入
一次一个执行部门
执行完再回总控
```

---

## 10. 最短工作流

如果你今天只想快速推进，按这个顺序：

1. `项目总控`：理解 + 分配
2. `产品PMO / 工程效能部 / 验证部`：先分析
3. `项目总控`：汇总 + 定优先级
4. `某一个执行部门`：小步改代码
5. `验证部`：确认验证
6. `项目总控`：收尾并安排下一步

---

## 11. 不知道怎么办时

如果你拿不准下一步该找谁，就永远先打开：

- `DailyTodo｜项目总控`

然后发：

```text
我现在的状态是：

【描述当前情况】

请你判断：
1. 现在该找哪个部门
2. 应该先分析还是先执行
3. 给我下一步可直接复制的提示词
```
