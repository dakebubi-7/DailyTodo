# 任务行长标题收回设计

## 目标

改善 DailyTodo 任务列表的横向信息密度：平常浏览时优先显示任务标题；用户准备操作某一条任务时，再显现拖拽、复盘和删除控件。

本设计已通过交互预览确认，预览文件位于 `.superpowers/brainstorm/content/task-row-long-title-retract.html`。

## 已确认的交互

### 默认浏览状态

- 每条任务持续显示完成勾选框、优先级和任务标题。
- 未完成编辑的长标题最多显示两行，超过两行时截断。
- 拖拽、复盘和删除不占用标题的可视宽度。
- 标签、排期日期和已完成样式继续沿用现有行为；本次不改变任务内容、完成逻辑、优先级或复盘数据。

### 操作状态

在桌面端，当鼠标悬停在任务行内，或任务行的任意内部控件获得键盘焦点时：

- 拖拽手柄从左侧显现。
- 复盘和删除控件从右侧显现，保持当前顺序和点击行为。
- 长标题从默认的两行高度平滑收为一行，并以省略号截断。
- 标题收回、控件显现和行表面状态在约 `180ms` 内完成；系统启用减少动态效果时不使用位移动画。
- 任务行获得克制的背景、边框或阴影反馈，使状态变化看起来是整行进入操作状态，而不是在标题上方浮出工具条。

短标题也遵循同一操作状态，但通常不会出现截断。编辑状态不触发标题收回：编辑输入框必须保留现有可用宽度和提交/取消行为。

### 触控设备

本次优化以桌面端任务列表为目标。没有稳定 hover 的设备保留当前可操作路径，不因本次变更引入“先点按展开、再点按操作”的额外状态机，也不让关键操作仅靠隐藏控件提供。此次不引入单独的右键菜单依赖，也不将复盘移出任务行；现有上下文菜单仍可作为补充入口。

## 实现边界

### 组件

- `src/components/TaskItem.tsx` 保持任务行结构、事件隔离和拖拽集成，必要时只添加语义化状态类名或包装元素。
- `src/components/taskItem/taskItemControls.tsx` 为非编辑标题提供可在“两行浏览”和“一行操作”之间切换的呈现结构，并保留 `title` 属性的完整任务文本。
- `src/components/taskItem/taskItemActionControls.tsx` 继续复用现有复盘/删除按钮和 aria 标签，不改变回调或权限条件。
- `src/styles/globals.css` 在最终的任务行样式层添加局部规则，避免破坏子任务、历史清理模式、不同主题和既有布局覆写。

不新增任务字段、持久化格式、业务状态或新的外部依赖。

### 状态与可访问性

- CSS 状态以任务行的 `:hover` 和 `:focus-within` 为主，确保纯键盘用户看到与鼠标用户一致的操作控件。
- 操作按钮在默认状态可视觉隐藏，但不能让已获得焦点的按钮不可见；`focus-within` 必须先使行进入操作状态。
- 完成、优先级、拖拽、复盘和删除的现有 `aria-label`、`title`、点击事件与事件冒泡隔离必须保持。
- 长标题仍保留原始完整文本作为辅助提示，视觉截断不能改变可访问名称或编辑入口。
- 历史清理模式不显示常规动作层，且不得因为本次样式新增空白操作区。

### 兼容范围

- 常规任务、父任务、带标签/排期任务和已完成任务。
- 明暗模式及应用支持的主题变体。
- 桌面鼠标、键盘导航和窄窗口布局。
- 子任务行只在现有结构可安全复用相同规则时采用；否则维持现状，避免扩大本次修改范围。

## 验收标准

1. 默认状态下，长任务标题可显示最多两行，拖拽、复盘和删除不挤占该宽度。
2. 悬停或键盘聚焦任务行时，长标题收为一行省略，左右操作区在同一过渡中显现。
3. 移出或失焦后，操作区隐藏，标题返回两行浏览状态。
4. 完成任务、变更优先级、拖拽排序、打开/编辑复盘、删除任务、双击编辑和右键菜单行为均无回归。
5. 已完成、带标签、带排期、父任务、历史清理和编辑中的任务不会出现控件重叠、文本遮挡或不可点击区域。
6. 在明暗主题和窄窗口中，标题、图标和行高保持可读且不溢出；减少动态效果设置下不产生突兀位移动画。

## 验证策略

- 为任务行呈现/类名的纯函数或结构行为补充聚焦测试，覆盖长文本、编辑态、清理态以及可用复盘按钮的条件。
- 运行现有任务动作与持久化验证脚本，确认本次仅改变呈现层。
- 在本地应用中手动检查默认、hover、键盘焦点、编辑、完成、标签、排期、窄窗口与明暗主题。
- 使用浏览器截图或 DOM 检查确认长标题从两行到一行省略的状态转换，以及操作控件的可见性和可聚焦性。

## 非目标

- 不把复盘放入专属右键菜单。
- 不设计浮动工具条或覆盖在标题上的操作面板。
- 不重构任务数据模型、任务列表虚拟化或拖拽实现。
- 不对无关的全局样式层进行整理。
