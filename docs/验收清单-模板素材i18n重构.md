## 5. 周报/月报生成的核心修复(必测)

这是本次修复的最关键问题:**找不到素材时,不再让 AI 瞎编**。

### 5.1 无素材场景(主修复点)

- [ ] 确认 Obsidian vault 路径已设好,但**本周没有任何日报 `.md` 文件**
- [ ] 在设置里点 **「生成周报」**(个人周报)
- [ ] **预期结果**:返回明确错误 **「没有找到本周期原始记录,请检查素材来源或手动选择素材文件。」** — **不应**生成任何带猜测内容的报告,不应消耗 LLM 调用
- [ ] 同样测月报(本月无日报也无可用周报时)→ 同样提示无素材

### 5.2 有素材场景

- [ ] 在 vault 下的「每日记录文件位置」目录放一份模拟日报 `.md`(例如 `logs/daily/DailyTodo/2026-06-10.md`,写几行今日工作+灵感+任务)
- [ ] 再点「生成周报」→ 应该能正常生成,内容应**基于你写的日报**,不应凭空编造
- [ ] 把测试日报删掉,再生成 → 又回到「没有找到本周期原始记录」

### 5.3 月报素材优先级

- [ ] 同时有「本月周报文件」+「本月日报文件」时,月报应**优先用周报**(对照 vault 目录确认产物是周报风格的汇总)
- [ ] 删除周报、只留日报 → 月报应**回落**到日报汇总
- [ ] 全删 → 又回到「没有找到素材」

## 6. 定时报告(后台静默)状态

- [ ] 在设置里打开**周报定时**(或月报定时)
- [ ] 确认**当前周期无素材**
- [ ] 触发定时(可改时间到 1 分钟后,或直接调短时间测试)— 等到点后
- [ ] **预期**:不弹阻塞窗口,主进程日志/状态区有「没有找到本周期原始记录」,不消耗 LLM
- [ ] 重新放上素材再触发 → 定时报告应能正常生成

---

## 7. 日报同步(用户最基础的工作流)

- [ ] 创建一个任务 → 勾选完成 → 写点今日工作/灵感随笔
- [ ] 点「同步到 Obsidian」
- [ ] 在 vault 对应路径下生成的日报 `.md` 文件应**包含**:
  - 今日工作
  - 灵感随笔
  - 每日任务(含你刚勾选的任务)
  - 复盘(可空,等 AI 填)
- [ ] **再次同步**(任务有新增) → 任务区**就地更新**,**不重复追加**;今日工作/灵感随笔区保留你之前的内容
- [ ] 切换「模板风格」预设 → 新建的下一天日报按新预设生成
