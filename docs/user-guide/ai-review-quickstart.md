# AI 自动复盘功能 - 快速开始

> 让 DailyTodo 自动生成每日复盘、周报、月报

---

## 功能介绍

DailyTodo 的 AI 自动复盘功能可以：

✅ **每天自动生成复盘**：基于你完成的任务、工作记录和灵感，自动生成当天的复盘总结  
✅ **自动生成明日待办**：未完成的任务自动结转，AI 还会给出建议  
✅ **提炼可复用知识**：从每日内容中提炼可沉淀的经验和要点  
✅ **生成个人周报/月报**：汇总一周/一月的工作，自动生成结构化报告  
✅ **生成对外工作周报**：面向汇报的正式版本，自动脱敏私人内容  
✅ **关机也不漏**：第二天打开自动补齐昨天的内容

## 第一步：准备 API Key

AI 复盘需要调用大语言模型（LLM）。你需要准备以下之一：

### 选项 A：DeepSeek（推荐新手）
- 访问 [DeepSeek 官网](https://platform.deepseek.com/)
- 注册账号并充值（很便宜，几块钱能用很久）
- 获取 API Key（格式：`sk-xxxxxxxx`）
- Base URL: `https://api.deepseek.com/v1`
- 模型：`deepseek-chat`

### 选项 B：OpenAI
- 访问 [OpenAI 平台](https://platform.openai.com/)
- 获取 API Key
- Base URL: `https://api.openai.com/v1`
- 模型：`gpt-4o-mini` 或 `gpt-4o`

### 选项 C：本地模型
- 使用 Ollama 或 LM Studio 运行本地模型
- Base URL: `http://localhost:11434/v1`（Ollama 默认）
- 模型：如 `llama3` 等

## 第二步：首次配置

### 方式 1：首次启动向导（推荐）

首次启动应用时会自动弹出 30 秒向导：

1. **选择模板**：
   - 使用默认模板（推荐）
   - 或点击「认我的模板」粘贴你自己的格式

2. **配置 AI**：
   - 填写 Base URL（如 `https://api.deepseek.com/v1`）
   - 填写 API Key（如 `sk-xxxxxxxx`）
   - 选择模型（如 `deepseek-chat`）

3. **设置时间**：
   - 勾选「每晚自动生成」
   - 设置时间（如 23:00）

点击「完成」后，配置会自动保存。

### 方式 2：手动配置

如果跳过了向导，可以在设置中配置：

1. 打开应用设置（Settings）
2. 找到「AI 自动复盘」区域
3. 填写配置：
   ```
   启用 AI 复盘: ✓
   Base URL: https://api.deepseek.com/v1
   API Key: sk-xxxxxxxx
   模型: deepseek-chat
   补偿扫描天数: 7
   定时生成: ✓ 每晚 23:00
   ```
4. 保存设置

## 第三步：开始使用

### 日复盘自动生成

1. **正常使用应用**：创建任务、标记完成、写工作记录
2. **点击同步到 Obsidian**
3. **打开生成的 daily 文件**（如 `logs/daily/2026-06-08.md`）
4. **查看自动生成的复盘**：

```markdown
<!-- DAILYTODO:REVIEW:START -->
<!-- DAILYTODO:AI_HASH:sha256:abc123... -->
🤖 AI 草稿

## 复盘
今天完成了 3 项任务，主要集中在 AI 复盘功能的收尾工作。值得保留的经验是完善了测试覆盖和文档，下次可以更早启动冒烟测试。

<!-- DAILYTODO:REVIEW:END -->
```

### 生成周报

1. 打开设置面板
2. 找到「报告生成」区域
3. 点击「生成本周周报」
4. 周报会保存到：`logs/weekly-review/2026-W23.md`

### 生成月报

1. 在设置面板点击「生成本月月报」
2. 月报会保存到：`logs/monthly-review/2026-06.md`

### 生成对外工作周报

1. 点击「生成对外工作周报」
2. 报告会保存到：`exports/weekly-reports/2026-W23.md`
3. ⚠️ 注意：对外报告会自动脱敏私人内容，仅包含工作相关信息

## 常见问题

### Q1: 生成的复盘不满意，能重新生成吗？
A: 可以。直接删除复盘段落的内容（保留标记），再次同步或手动触发补偿扫描即可。

### Q2: 我手动修改了复盘，会被覆盖吗？
A: **不会**。系统使用 `AI_HASH` 指纹检测，一旦你修改了内容，下次就会跳过不覆盖。

### Q3: 如何冻结某个复盘段落，永久不让 AI 改？
A: 在段落开头添加冻结标签：
```markdown
<!-- DAILYTODO:FREEZE -->
这段内容被冻结，AI 不会修改
```

### Q4: 关机了会漏掉复盘吗？
A: **不会**。下次启动时会自动补偿扫描最近 7 天，漏掉的会自动补上。

### Q5: 我想用自己的模板，怎么办？
A: 在设置中点击「认我的模板」，粘贴你的模板，AI 会自动识别结构并配置。

### Q6: API 调用失败会破坏我的文件吗？
A: **不会**。所有写入操作都有原子性保护和外部修改检测，失败时绝不写入。

### Q7: 统计数字（完成率、任务数）准确吗？
A: **准确**。所有数字由程序计算，不是 AI 生成的。

### Q8: 生成的内容能直接交给领导吗？
A: **不建议**。AI 生成的内容都标注为「🤖 AI 草稿」，需要你复核后再使用。对外周报更要仔细检查。

## 高级配置

### 自定义段落

在设置面板的「段落配置」区域，你可以：

1. **调整段落顺序**：拖拽段落上下移动
2. **控制段落生成方式**：
   - `AI 自动写`：由 AI 生成
   - `我自己写`：跳过，手动填写
   - `自动结转任务`：程序确定性生成

3. **调整 Prompt**（高级）：
   - 点击段落右侧的「编辑 Prompt」
   - 修改生成指令，如改变语气、长度、侧重点

### 模板识别

如果你有一个特殊格式的日记模板：

1. 点击「认我的模板」
2. 粘贴你的模板内容，如：
   ```markdown
   ## 整理未完成
   ## 明日要完成
   ## 下一步
   ## 今日总结
   ```
3. AI 会识别结构并建议配置
4. 确认后自动应用

### 预设与覆盖

- 「预设」是默认配置，会随应用升级自动更新
- 「覆盖」是你的个性化修改，会保留
- 点击「恢复默认」可以清除所有覆盖

## 隐私与安全

### 数据存储
- ✅ 所有日记文件存储在本地
- ✅ API Key 加密存储在本地配置中
- ✅ 不会上传你的日记到任何服务器（除了调用你配置的 LLM 服务）

### LLM 调用
- ⚠️ 日复盘会把当天的任务和工作记录发送给 LLM 服务商
- ⚠️ 周报/月报会发送整周/整月的内容
- ✅ 对外报告会先物理脱敏，剔除 `private`/`secret` 标签的内容

### 建议
- 如果对隐私敏感，建议使用本地模型（Ollama 等）
- 或在灵感闪念等私人段落添加 `<!-- tag: private -->` 标签
- 对外周报一定要人工复核后再提交

## 故障排查

### 问题：生成失败，提示「缺少 API Key」
**解决**：在设置中填写 API Key，确保格式正确（如 `sk-xxxxxxxx`）

### 问题：生成失败，提示「LLM 返回 401」
**解决**：API Key 无效或过期，检查 Key 是否正确，是否已充值

### 问题：生成失败，提示「timeout」
**解决**：网络慢或模型响应慢，可以在设置中增加超时时间（默认 90 秒）

### 问题：生成的内容很奇怪/不相关
**解决**：
1. 检查选择的模型是否合适（推荐 `deepseek-chat` 或 `gpt-4o-mini`）
2. 尝试调整 Prompt，增加更明确的指令
3. 确保当天有足够的任务和记录作为输入

### 问题：复盘内容被覆盖了
**解决**：
1. 检查是否有 `AI_HASH` 行，如果没有说明是纯手写，不会被覆盖
2. 检查是否有冻结标签
3. 如果确实被覆盖，可以在 Git 历史中找回（如果 Vault 在 Git 管理下）

### 问题：周报生成失败
**解决**：
1. 确保本周至少有 1 天有日记记录
2. 检查日记文件路径是否正确
3. 查看应用日志（开发者工具控制台）
