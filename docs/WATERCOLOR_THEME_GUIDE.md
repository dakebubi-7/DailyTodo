# 🎨 水彩画风主题 - 快速启动指南

## ✨ 主题已成功添加！

优雅的"水彩画风"主题已经成功集成到 DailyTodo 应用中。这是一个充满艺术气息和诗意的主题设计。

## 🎨 主题特点

### 核心设计元素
- 🌊 **柔和渐变** - 水彩般的颜色渐变效果
- 🎈 **大圆角** - 24px 圆角，柔和的边缘
- 💧 **半透明效果** - 水彩的透明叠加特性
- 📄 **纸张质感** - 温暖的米色背景 (#faf8f5)
- ✨ **毛玻璃效果** - backdrop-blur 增强层次感
- 🎯 **轻盈字体** - font-weight: 300，精致优雅

### 颜色系统
```css
主色调：#4a6fa5 (水彩蓝)
辅助色：#7fa3c9 (浅水彩蓝)
高亮色：#a8c5e3 (淡水彩蓝)
背景色：#faf8f5 (纸张米色)
文字色：#6a7a8a (柔和灰)
```

### 交互效果
- 按下缩放：scale(0.98)
- 过渡时间：400ms ease-out
- 柔和阴影：0 4px 20px rgba(74,111,165,0.12)
- 触摸目标：≥ 44px

## 🚀 快速启动

### 1. 启动应用

```bash
cd app
npm run dev
```

### 2. 切换到水彩画风主题

1. 点击右上角的 **⚙️ 设置图标**
2. 进入 **"Personalization"** (个性化设置)
3. 在"外观风格"部分，找到 **"水彩画风"** (Watercolor) 主题卡片
4. 点击该卡片，主题将立即应用
5. 自动进入主题详细设置页面

### 3. 自定义主题参数

#### 基础透明度
- **窗口透明度**：85% (推荐)
- **面板透明度**：80% (推荐)
- **模糊强度**：16px (推荐)
- **圆角大小**：24px (推荐)

#### 高级透明度
- **顶部区域**：80% - 标题栏和头部
- **任务卡片**：75% - 任务列表卡片
- **按钮输入框**：60% - 半透明效果
- **弹出菜单**：90% - 设置面板和日历

#### 颜色自定义
- **主色**：#4a6fa5 (水彩蓝)
- **强调色**：#7fa3c9 (浅水彩蓝)

## 🎯 设计规范遵循

严格遵循 `watercolor-style-app-ui-prompt.md` 的设计规范：

### ✅ 必须包含
- ✅ `rounded-2xl` - 大圆角 (24px)
- ✅ `border border-[#4a6fa5]/20` - 柔和边框
- ✅ `shadow-[0_4px_20px_rgba(74,111,165,0.12)]` - 柔和扩散阴影
- ✅ `active:scale-[0.98]` - 缩放反馈
- ✅ `transition-all duration-400 ease-out` - 流畅过渡
- ✅ `font-light` - 轻盈字体 (300)
- ✅ `min-h-[44px]` - 触摸目标
- ✅ `backdrop-blur-md` - 毛玻璃效果

### ❌ 禁止使用
- ❌ 无 `rounded-none`, `rounded-sm` - 小圆角
- ❌ 无 `border-dashed` - 虚线边框
- ❌ 无 `shadow-[2px_2px_0px` - 硬边缘阴影
- ❌ 无 `font-bold`, `font-semibold` - 粗字体
- ❌ 无 `hover:` - 移动端不使用悬停

## 🔧 故障排除

### 主题没有显示？
1. 确保应用已重新构建：`npm run build`
2. 清除浏览器缓存
3. 重启应用

### 样式显示不正确？
1. 检查 `watercolor-theme.css` 文件是否存在
2. 检查 `globals.css` 是否正确导入
3. 查看浏览器控制台是否有错误

### 圆角太大或太小？
1. 进入主题设置页面
2. 调整"圆角大小"滑块 (4-36px)
3. 推荐值：24px

### 透明度不合适？
1. 进入主题设置页面
2. 分别调整各区域的透明度
3. 推荐值：窗口 85%，面板 80%
