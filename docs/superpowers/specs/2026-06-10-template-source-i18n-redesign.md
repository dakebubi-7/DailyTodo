# DailyTodo 模板、素材来源与设置页双语重构设计

## 背景

当前 DailyTodo 的模板体系把几个概念混在一起：日报写入路径、日报结构、周报/月报生成提示词、AI 模板识别、报告素材读取。结果是用户找不到“每日记录位置”，周报可能读不到原始日报却继续让 AI 生成，设置页也暴露了大量英文字段名，中文体验不一致。

本次目标是一次性打通：日报模板、个人周报、个人月报、对外周报、对外月报、素材来源、AI 模板识别、设置页中英双语。

## 目标

1. 用户可以在设置页直接查看、编辑、恢复所有默认模板。
2. 用户可以粘贴或导入 `.md` 文件，让 AI 识别日报/周报/月报/对外报告模板。
3. 周报/月报生成必须基于真实素材；找不到素材时停止生成并提示，不允许 AI 靠统计猜测。
4. 日报保留三个基础能力：今日工作、灵感随笔、每日任务；用户仍可自由调整 Markdown 模板。
5. 设置页所有可见文案跟随全局语言设置，中文模式不显示英文配置名。
6. 个人报告和对外报告都纳入同一套清晰配置，不再只改一部分。

## 非目标

1. 不改变任务数据本身的存储结构。
2. 不实现复杂的 Obsidian 全库语义搜索。
3. 不引入新的外部模板市场或在线模板中心。
4. 不要求用户必须采用 DailyTodo 默认 Markdown 标题。

## 架构边界

本次重构按三个边界拆分，避免继续把概念混在一起：

1. 模板配置
   - 保存用户可编辑的日报 Markdown 模板，以及个人周报、个人月报、对外周报、对外月报生成模板。
   - 负责“未来输出长什么样”。
2. 素材来源配置
   - 保存日报、周报、月报生成时应该去哪里找原始 `.md` 素材。
   - 负责“AI 生成前读什么内容”。
3. AI 模板识别
   - 输入用户提供的模板或历史文件，输出可编辑草稿。
   - 只辅助更新模板配置，不直接生成报告。

Electron 主进程负责文件读取、路径安全、LLM 调用和报告写入；React 设置页负责编辑配置、触发识别、展示素材测试结果。所有路径规则必须继续限制在 Obsidian vault 内部，禁止绝对路径和 `..` 逃逸。

## 数据模型调整

在现有设置上扩展，不做破坏性替换：

- `dailyMarkdownTemplate`：日报 Markdown 模板。
- `dailySourceRules`：日报素材规则列表，默认由 `dailyNotePath` 派生。
- `weeklySourceMode`：个人周报素材策略。
- `monthlySourceMode`：个人月报素材策略。
- `externalWeeklySourceMode`：对外周报素材策略。
- `externalMonthlySourceMode`：对外月报素材策略。
- 现有 `weeklyPrompt`、`monthlyPrompt`、`externalWeeklyPrompt`、`externalMonthlyPrompt` 继续保留，作为用户可编辑模板字段。

AI 识别接口按目标类型返回统一结构：

- `target`: `daily` / `personalWeekly` / `personalMonthly` / `externalWeekly` / `externalMonthly`
- `templateDraft`: 可应用的模板草稿
- `missingCoreFields`: 缺失的核心内容，仅日报必须检查
- `unmappedSections`: 未识别内容
- `notes`: 给用户看的说明
- `confidence`: `high` / `medium` / `low`

## 设置页信息架构

新增或重组一个一级区域：`模板与素材` / `Templates & Sources`。

该区域包含五个子区：

1. 日报模板
2. 个人报告模板
3. 对外报告模板
4. 素材来源
5. AI 模板识别

如果当前设置页空间有限，可以使用折叠面板；每个折叠面板标题、说明、按钮、占位符都走 i18n。

## 日报模板

### 字段

- 每日记录文件位置 / Daily note file path
  - 默认：`logs/daily/DailyTodo/{{date}}.md`
  - 显示明确说明：`{{date}} 会替换为日期，例如 2026-06-10`。
- 日报 Markdown 模板 / Daily note Markdown template
  - 大文本框。
  - 初始值来自内置默认模板。
  - 用户修改后保存到设置。
- 任务导出文件位置 / Task export file path
  - 默认：`logs/daily/DailyTodo/tasks/{{date}}.md`
  - 作为高级项显示，但中文模式必须中文化。

### 必须能力

日报模板必须支持写入以下内容：

1. 今日工作
2. 灵感随笔
3. 每日任务

这不要求用户 Markdown 标题必须叫这三个名字。实现上可以通过模板变量或识别后的映射来完成，例如：

- `{{work}}`
- `{{inspiration}}`
- `{{tasks}}`

如果用户导入的日报模板没有识别出某个核心能力，AI 识别结果应显示“缺少：每日任务”等明确提示，并生成可编辑草稿，而不是只显示“识别不够确定”。

### 操作

- 导入 `.md` 模板
- 粘贴模板并 AI 识别
- 应用识别草稿
- 恢复默认日报模板
- 预览今日日报

## 个人报告模板

包括个人周报和个人月报。

### 个人周报字段

- 个人周报输出目录 / Personal weekly report directory
  - 默认：`logs/weekly-review`
- 个人周报生成模板 / Personal weekly generation template
  - 大文本框。
  - 默认填入内置个人周报 system prompt。
  - 用户可直接修改。

### 个人月报字段

- 个人月报输出目录 / Personal monthly report directory
  - 默认：`logs/monthly-review`
- 个人月报生成模板 / Personal monthly generation template
  - 大文本框。
  - 默认填入内置个人月报 system prompt。
  - 用户可直接修改。

### 操作

每种报告都提供：

- 导入 `.md` 范例
- 粘贴范例并 AI 识别
- 应用识别出的生成模板
- 恢复默认模板
- 生成当前周期报告

AI 识别周报/月报时，输入可以是用户旧周报、旧月报或目标格式文件。输出不是最终报告，而是“以后生成报告用的提示词/格式说明”。

## 对外报告模板

包括对外周报和对外月报。

### 对外周报字段

- 对外周报输出目录 / External weekly report directory
  - 默认：`exports/weekly-reports`
- 对外周报生成模板 / External weekly generation template
  - 大文本框。
  - 默认填入内置对外周报 system prompt。
  - 用户可直接修改。

### 对外月报字段

- 对外月报输出目录 / External monthly report directory
  - 默认：`exports/monthly-reports`
- 对外月报生成模板 / External monthly generation template
  - 大文本框。
  - 默认填入内置对外月报 system prompt。
  - 用户可直接修改。

### 对外报告规则

1. 对外报告继续执行脱敏逻辑。
2. 对外报告模板必须强调忠于原始记录，不编造。
3. 找不到素材时停止生成，不输出空泛汇报。
4. 生成结果仍写入 exports 目录。

## 素材来源

新增清晰的素材来源配置，避免用户必须猜“每日记录位置”在哪里。

### 日报素材来源

- 默认使用“每日记录文件位置”。
- 支持用户配置一个或多个目录/文件规则。
- 支持日期占位符：`{{date}}`。
- 支持扫描包含日期的 `.md` 文件作为兜底。

建议 UI：

- 日报素材规则列表
- 添加规则
- 删除规则
- 测试当前日期

“测试当前日期”会显示实际找到的文件路径。

### 周报素材来源

默认策略：聚合所选 ISO 周内找到的日报。

可选策略：

1. 自动聚合本周日报
2. 使用已有周报文件
3. 自动聚合日报，找不到时允许手动选择素材文件

推荐默认使用第 3 种。

### 月报素材来源

默认策略：

1. 优先读取本月相关个人周报。
2. 没有周报时回退到本月日报。
3. 都没有时停止生成并提示。

对外月报同理，但素材需要先经过脱敏。

### 找不到素材时

所有报告生成入口必须先检查素材数量。

如果没有找到素材，返回明确错误：

- 中文：`没有找到本周期原始记录，请检查素材来源或手动选择素材文件。`
- English: `No source notes found for this period. Check source settings or choose files manually.`

此时不调用 LLM。

## AI 模板识别

AI 模板识别按用途拆分，不共用一个模糊入口。

### 日报模板识别

输入：日报模板或用户过去写过的一篇日报。

输出：

- 日报 Markdown 模板草稿
- 核心内容映射
- 未识别内容列表
- 缺失核心能力列表
- 简短说明

状态：

- 识别成功
- 部分识别成功
- 缺少核心模块
- 未能可靠识别，已生成可编辑草稿

### 周报/月报模板识别

输入：用户旧周报、旧月报或目标格式模板。

输出：对应报告的生成提示词。

状态：

- 识别成功，可应用
- 部分识别成功，建议检查
- 未能可靠识别，已保留当前模板

### 对外报告模板识别

与个人报告类似，但输出提示词必须保留：

- 对外语气
- 脱敏约束
- 不编造约束
- 事实来自原始记录

## 生成流程

### 生成日报

1. 用户输入今日工作、灵感随笔、任务。
2. 使用日报 Markdown 模板渲染内容。
3. 写入每日记录文件位置。
4. 如果模板缺少核心变量，使用安全兜底插入核心内容，并提示用户模板需要调整。

### 生成个人周报

1. 根据所选周计算日期范围。
2. 按素材来源规则查找本周日报。
3. 找不到素材则停止并提示。
4. 找到素材后，把素材全文、确定性统计、个人周报生成模板传给 LLM。
5. 写入个人周报输出目录。

### 生成个人月报

1. 根据所选月计算日期范围。
2. 优先查找本月周报。
3. 没有周报则查找本月日报。
4. 找不到素材则停止并提示。
5. 找到素材后，把素材、确定性统计、个人月报生成模板传给 LLM。
6. 写入个人月报输出目录。

### 生成对外周报/月报

1. 使用同样的素材查找规则。
2. 找不到素材则停止。
3. 找到素材后先脱敏。
4. 使用对外报告模板生成。
5. 写入 exports 目录。

### 自动生成

定时触发的周报/月报必须复用同一套生成入口和素材检查逻辑。自动生成时如果找不到素材，不弹出阻塞窗口，只记录状态并在设置页或最近生成状态中显示原因；同样不调用 LLM。

## 设置页双语要求

所有设置页可见文本必须进入 i18n：

- 分区标题
- 字段名称
- 字段说明
- 占位符
- 按钮
- 状态提示
- 错误提示
- 高级设置标题
- AI 识别结果
- 默认模板说明
- 恢复默认确认文案

中文模式下不展示内部字段名：

- 不展示 `dailyNotePath`
- 不展示 `weeklyPrompt`
- 不展示 `externalMonthlyDir`
- 不展示 `presetId`

对应中文为：

- 每日记录文件位置
- 个人周报生成模板
- 对外月报输出目录
- 模板风格

英文模式下使用自然英文，不直接暴露代码变量名。

## UI/UX 规则

1. 高级项默认折叠，避免吓到普通用户。
2. 每个危险操作提供恢复路径，例如“恢复默认”。
3. 长文本模板编辑区必须有明确 label 和 helper text，不能只靠 placeholder。
4. 异步 AI 识别和生成按钮必须有 loading 状态，期间禁用重复点击。
5. 错误信息必须说明原因和下一步操作。
6. “测试素材来源”结果要显示找到的文件数量和路径，便于用户排查。
7. 所有按钮保持 44px 以上可点击高度。

## 数据兼容

已有设置需要平滑迁移：

- 旧的 `weeklyPrompt` 继续作为个人周报生成模板。
- 旧的 `monthlyPrompt` 继续作为个人月报生成模板。
- 旧的 `externalWeeklyPrompt` 继续作为对外周报生成模板。
- 旧的 `externalMonthlyPrompt` 继续作为对外月报生成模板。
- 旧的 `dailyNotePath` 继续作为默认日报路径和默认日报素材规则。

如果用户从未设置过模板，则使用内置默认值填充。

## 测试与验证

需要覆盖：

1. 默认设置下可以看到所有模板文本。
2. 中文模式设置页没有英文内部字段名。
3. 英文模式设置页没有中文残留。
4. 修改日报模板后，生成日报使用新模板。
5. 恢复默认日报模板可恢复内置模板。
6. AI 识别日报模板能返回可编辑草稿。
7. AI 识别周报、月报、对外周报、对外月报能写入对应模板字段。
8. 周报没有素材时不调用 LLM。
9. 月报没有周报但有日报时可回退日报。
10. 对外报告生成前执行脱敏。
11. 素材来源测试能显示实际命中的文件。
12. 旧设置迁移后不丢失用户原有 prompt 和目录。

## 实施顺序建议

1. 补齐 i18n 文案和设置页信息架构。
2. 抽出模板默认值与可编辑字段。
3. 增加素材来源配置和测试入口。
4. 改造周报/月报生成前的素材检查。
5. 拆分 AI 模板识别入口。
6. 补验证脚本。
7. 手动启动应用检查设置页中文/英文体验。

## 验收标准

1. 用户能在设置页直接找到“每日记录文件位置”。
2. 用户能在设置页编辑日报、个人周报、个人月报、对外周报、对外月报模板。
3. 用户能从 `.md` 或粘贴文本 AI 识别上述模板。
4. 周报/月报没有原始素材时不再生成猜测内容。
5. 中文设置页没有英文内部字段名。
6. 英文设置页没有中文残留。
7. 所有旧设置仍可使用。
