# 极简深夜标题栏激活态增强设计（2026-06-21）

## 背景

用户反馈在极简纯白的深夜主题下，标题栏最上方的三个主操作按钮——置顶、锁定、设置——激活态不够明显。当前问题不是布局或交互缺失，而是激活态与普通 hover 态的视觉差距过小，导致“已开启/已选中”的状态识别不够直接。

相关入口位于 `app/src/components/TitleBar.tsx`，具体按钮为：
- 置顶：`pinned` -> `titlebar-icon-active`
- 锁定：`lockWindowPosition` -> `titlebar-icon-active`
- 设置：`settingsOpen` -> `titlebar-icon-active`

## 目标

只增强极简主题深夜模式下这三个按钮的激活态可见性，让用户一眼看出哪个状态已开启，同时保持黑白极简风格，不引入蓝色强调、不改变尺寸、不改变布局。

## 非目标

- 不调整最小化、关闭按钮
- 不调整其它主题
- 不调整按钮尺寸、间距、布局
- 不改变 hover 和 press 的交互节奏
- 不引入高饱和色或厚重实心胶囊效果

## 设计方案

采用“更强描边 + 极弱内外高光”的方案。

### 未激活态
保持现状，不主动增强，继续作为低干扰的背景操作按钮。

### 激活态
仅在 `dark + minimal` 场景下，对 `titlebar-icon-active` 做以下增强：
- 边框更亮，显著高于普通 hover 的边框强度
- 图标颜色提亮到接近纯白
- 保持暗底，但底色只做轻微增强，不改成大面积高亮填充
- 增加很弱的内高光与外发光，帮助在深色背景上形成“已点亮”的状态识别

### 视觉原则
- 仍然是极简黑白，不做品牌色高亮
- 激活态必须明显强于 hover 态
- 激活态不应抢走关闭按钮或窗口主层级的注意力

## 实现范围

优先只改 `app/src/styles/globals.css` 中 `minimal + dark` 下标题栏按钮激活态覆盖规则。

如果现有 verifier 没覆盖这一点，则补一条最小断言，检查：
- 极简深夜主题存在专门的 `titlebar-icon-active` 强化规则
- 该规则和通用 hover 态有明确视觉区分
- 作用范围不扩散到 `invisible` / `neumorphism` / `watercolor`

## 验证

最小相关验证：
- `npm run verify:ui-feedback-regressions`
- 若新增/更新专用 verifier，则同时跑该 verifier

## 风险与控制

风险：描边增强过头后会让按钮看起来像厚重胶囊，破坏极简感。

控制方式：
- 只增强激活态，不增强普通态
- 以描边和极弱高光为主，避免大面积亮底
- 只在 `minimal + dark` 下定向覆盖，避免影响其它主题
