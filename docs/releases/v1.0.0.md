# DailyTodo v1.0.0

[English](#english) · [简体中文](#简体中文)

## English

DailyTodo v1.0.0 is the first portfolio-ready public release of a local-first Windows desktop workspace for daily planning, focus, reflection, and next-action selection.

### Highlights

- Bilingual interface: switch between Simplified Chinese and English in **Settings → General → Language**.
- Daily execution workspace with priorities, subtasks, progress, carry-over tasks, and task sources.
- AI-assisted daily, weekly, monthly, and external reviews with multi-account provider settings.
- Obsidian daily-note synchronization and managed AI review blocks.
- Desktop-focused interaction: compact layouts, transparent/glass styling, edge auto-hide, focus surface, and recovery behavior.
- Review-to-focus handoff: inspect an AI-suggested next action and explicitly adopt it as today’s focus.

### Quality and fixes

- Long generated-review content scrolls within the dialog.
- Generated-review dialogs can be closed with **Escape**.
- AI review account and daily-note error paths have additional safety handling and regression coverage.
- Verified with **69 test files / 272 tests**, TypeScript type checking, and a production build.

### Installation

Download `DailyTodo.exe`, run it, and follow the installer. This Windows installer is currently unsigned, so SmartScreen may show a warning on first launch.

## 简体中文

DailyTodo v1.0.0 是首个适合在作品集 / 简历中展示的公开版本：一款本地优先的 Windows 桌面工作台，用于每日规划、专注执行、复盘与下一步行动选择。

### 主要功能

- **中英双语界面**：在 **设置 → 通用 → 语言** 中切换「简体中文」或「English」。
- 每日执行工作台：优先级、子任务、完成进度、任务延期与任务来源。
- AI 辅助日 / 周 / 月度及外部复盘，支持多个 AI 服务商账号配置。
- 同步 Obsidian 每日笔记，并管理 AI 复盘内容块。
- 面向桌面专注的交互：紧凑布局、透明 / 毛玻璃样式、边缘自动隐藏、聚焦桌面和恢复行为。
- 将 AI 推荐的下一步行动审核后，一键采纳为今日聚焦。

### 质量与修复

- 较长的 AI 复盘内容可在弹窗内正常滚动。
- 生成的复盘详情弹窗支持按 **Escape** 关闭。
- 为 AI 账号设置和每日笔记异常路径增加保护与回归测试。
- 已通过 **69 个测试文件 / 272 个测试**、TypeScript 类型检查及生产构建验证。

### 安装说明

下载 `DailyTodo.exe` 后运行并根据安装向导完成安装。Windows 安装包目前尚未签名，首次启动时可能出现 SmartScreen 提示。
